About Dataset
If you find this dataset helpful for your analysis or machine learning projects, please consider giving it an upvote. It helps increase visibility and supports further dataset development.

This dataset simulates student academic performance based on study behavior, engagement, and lifestyle factors.

It contains information about students' demographic background, study habits, participation in academic activities, and exam results.

The dataset was synthetically generated to mimic realistic educational data patterns and can be used for:

• Exploratory Data Analysis (EDA)
• Predictive modeling
• Classification tasks
• Educational data mining
• Machine learning practice

The target variable includes:

final_exam_score (regression task)
grade_category (classification task)
pass_fail (binary classification)
Researchers and data science practitioners can use this dataset to explore how different factors such as study hours, attendance, and social media usage may influence academic performance.
